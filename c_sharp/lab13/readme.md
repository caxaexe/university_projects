# Великая памятка

## Вариант 1 - Массив команд (Action[])
Идея: команда = просто функция  
Мы кладём в массив список действий, и при выборе пункта меню просто вызываем нужную функцию по индексу.
  
Без объектов, без делегатов - обычные функции в массиве.

## Вариант 2 - Делегаты (Command)
Идея: команда = функция, но тип функции - наш собственный  
Мы создаём делегат Command, то есть свой тип “функции”.  
Дальше делаем массив таких функций.  
  
Это почти то же самое, что Action[], но формально - через делегат, что показывает владение типами и сигнатурами методов.

## Вариант 3 - Интерфейсы команд (ICommand)
Идея: каждая команда = отдельный объект с методом Execute()  
Мы создаём интерфейс ICommand, у которого есть метод Execute().  
Каждая команда - это отдельный класс, реализующий интерфейс.  
Это уже полиморфизм:  
 - все команды разного типа
 - но вызываются одинаково -> command.Execute()

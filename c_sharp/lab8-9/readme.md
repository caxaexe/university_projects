# Задание 

Библиотека. Есть 5 книг. У каждой книги есть название, год выпуска и статус (если ее кто-то взял, или нет).

Возможные операции:

Кто-то берет книгу по имени (находим книгу, меняем статус);
Кто-то отдает книгу по имени - в этом случае, если такой книги не было, даем ошибку;
Просматриваем все книги;
Реализуйте эту систему в коде, руководствуясь информацией из видео. Важно соблюсти техники программирования, описанные в видео:

Использование классов или структур для группирования данных;
Использование массива для представления нескольких книг;
Использования цикла для обработки всех книг;
Рекомендуется создание функций для конкретных операций (заимствование, возвращение, просмотр - все это будут отдельные функции), особенно если они используются несколько раз в программе.

Важно также понять, почему данный подход удаляет повторяющийся код, и тем самым есть лучше банального подхода.

Убедитесь, что nullability включен в вашей программе. Добавьте также следующую строчку, чтобы вы не могли скомпилировать программу за наличием каких бы то ни было проблем в ней.
```csproj
<TreatWarningsAsErrors>true</TreatWarningsAsErrors>
```
  
  
Что такое null?
 > null - это значение, указывающее на отсутствие ссылки (адреса памяти). Хранится в памяти как 0.

Почему тип int не позволяет значение null?
 > int - это целочисленный тип, а не ссылочный тип. 0 как int это число 0, а не пустая ссылка.

Почему int? и string? работают по-разному? Как вообще работает int??
 > string? может быть null, потому что string ссылочный тип. int не может быть null, потому что это значимый тип (value type). чтобы int тоже мог быть null, придумали int? тоесть int всегда число, а int? либо число, либо null.

Что делает оператор !?
 > ! позволяет присвоить результат выражения, который возмножно null, переменной, которая не поддерживает null

Приведите пример, как с помощью оператора ! можно обойти гарантии nullability компилятора.
```cs
Console.WriteLine("Введите название книги: ");
string returnBook = Console.ReadLine()!;
```

Чего позволяет достичь required?
 > required позволяет гарантировать, что гарантии nullability компилятора будут всегда соблюдены.

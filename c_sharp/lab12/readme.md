# Памятка

1. Разделили книги на два списка (List<Book>)

Мы сделали:
freeBooks - список свободных книг
takenBooks - список занятых книг

List<Book> - это просто коробка, куда можно класть много объектов Book.
В отличие от массива, список можно легко:
* добавлять элементы
* удалять
* переносить из одного списка в другой

Это нужно, чтобы удобно брать и возвращать книги.

---

2. Сделали фильтр (LibraryFilter)

Фильтр - это набор условий, по которым мы выбираем книги.

Например:
* название содержит слово
* начинается с буквы
* автор
* книга свободна или занята

Фильтр работает как фильтр на сайте магазина: ты задаёшь параметры → показываются только подходящие книги.

---

LibraryFilter хранит условия

Он хранит:
* что должно быть в названии
* чего не должно быть
* с чего начинается
* автор
* состояние (free / taken / any)

Если поле пустое - условие просто не используется.

---

InputLibraryFilter - переводит пользовательский ввод в фильтр

Этот класс:
* принимает строки, которые ввёл пользователь
* превращает их в правильные значения
* делает пустые строки → null
* проверяет состояние (free/taken/any)

То есть он готовит фильтр, чтобы он был корректным.

---

5. Метод ShowBooksFilter применяет фильтр

В Library есть метод, который:
* берёт все книги
* проверяет каждое условие фильтра
* показывает только те, которые подходят

То есть это как «поиск» по библиотеке.

---

6. Мы сделали полноценную мини-систему библиотеки

Она умеет:
* хранить книги
* брать книги
* возвращать книги
* выводить все книги
* выводить книги по фильтрам (как поиск)

---

В двух словах:

List<Book> - это удобная коробка для хранения книг.  
LibraryFilter - это набор условий для поиска.  
InputLibraryFilter - переводит ввод пользователя в фильтр.  
Library - применяет фильтр и управляет книгами.
